03 · Import & arrange

Build a multitrack session

Open media through the Import or Open dialog, or drop files directly into the application window.

Audio and video sources

Each imported file becomes a track. For video, the audio stream is extracted for editing and playback, while the source video path is retained for a later video export.

Batch imports proceed file by file. A failed file is reported while the rest of the batch can continue; Cancel stops the cancellable operation.

Position tracks in time

Use the per-track Start s value to place a clip relative to project start. Tracks are added in import order. Project duration follows the end of the latest track.

There is no dedicated clip-drag positioning or track-reordering gesture; use the offset field.

04 · Timeline & transport

Navigate, audition, refine

Transport and timeline controls make it easy to inspect a session, repeat a passage, and focus an edit.

Transport

Record, Play, Pause, Stop, seek with the position slider, and monitor current time. Space starts or resumes playback. Long cancellable operations expose Cancel; Escape is the cancel shortcut.

Timeline navigation

Zoom from 1× to 16×, pan horizontally with Scroll, and use Fit to show the full project. Ruler tick spacing adapts to the visible range; the playhead and progress overlay track playback.

Selection & trim

Enter selection start/end times in seconds. Optional 0.1-second snapping rounds the boundaries. Trim keeps the selected range on the current track.

Looping

Set Loop start and end in seconds and enable Loop. The end must follow the start; disable Loop to stop repeating the selected interval.

Speed edit

Apply a preset from 0.5× to 4× to the selected track. This renders a resampling edit, changing both duration and pitch—it is not a real-time transport rate control.

Undo & redo

Reverse recent audio-buffer edits on the selected track. Up to eight audio edits per track are retained; project-wide history of track management and mixer changes is not provided.

Selection, looping, and the playhead are independent: selection defines a trim region, loop bounds define repeat playback, and the transport position controls where playback begins.

05 · Live visual feedback

See the signal as it plays

The spectrogram is generated from incoming live samples during playback or recording—not from a static analysis of the selected file.

Live-feed spectrogram

  • Blank while idle; starts drawing only when a live source begins.
  • Samples come from the playback output feed or microphone recording input.
  • New frequency-spectrum columns are drawn continuously during active playback/recording.
  • Stereo channels are analyzed independently to avoid cancellation when channels are out of phase.
  • Video playback is visualized through its extracted audio signal; silent source audio correctly produces little or no visible energy.

Waveforms & meters

Track waveforms show precomputed min/max peaks for the clip. Peak/RMS meters and clipping indicators provide approximate track-level feedback during playback.

Illustrative artwork. The live spectrogram itself updates from audio captured by the application during playback or recording.

The track waveform is a visual overview prepared from clip samples; the spectrogram is different—it is the live spectrum of the signal currently flowing through playback or recording.

Preview before committing

Preview renders the selected operation and auditions its result without replacing the track. Apply commits the rendered buffer. For two-track operations such as Merge, the neighboring track supplies the secondary audio.

Two kinds of level control

Track Gain and Pan remain adjustable mixer settings. Gain, Pan, EQ, dynamics, and other entries in the toolset are audio edits that render into the track buffer.

08 · Sound design & FX

A library that grows with the project

Quickly add a procedural starting point, organize personal audio, or source a licensed sound from an external archive.

100 built-in procedural effects

Generated sounds are available without downloading assets, organized into nine themed preset families and a set of focused utility sounds.

  • Haunted winds & ghostly voices
  • Chimes, bells, strings & dark drones
  • Cinematic impacts, textures & static
  • Creatures, whispers, risers & transitions
  • Noise, atmosphere, synth, metal, foley and more

Double-click a library entry to add it as a new track. Select an entry as a bridge sound for Mend Join.

Local FX library

Import supported audio into a chosen category, create category folders, filter the library, and track the user-clip count. The library supports up to 500 user audio clips.

HTTPS downloads & sound archives

Download an audio file from an HTTPS URL (maximum 200 MB per file); downloads are cached locally. Browse links to public sound archives from inside the library.

A link is not a licence. Review the asset’s terms and permissions before distributing or using it commercially.

Mend Join

Join the selected track with its neighbor and blend a chosen library sound across the splice. If the selected track is last, the previous track is used as the first segment. The operation replaces the first track’s audio and removes the second track.

09 · Projects & continuity

Keep sessions portable

Named project files preserve the editable session context; recovery snapshots help restore recent work after an interruption.

Save a project

Save creates a .bssa archive with each track’s current audio plus track name/order, offset, gain, pan, mute/solo state, and source references.

Open a project or media

Open accepts a saved project or audio/video files. Opening a project replaces the tracks currently in the workspace; save a separate copy first if needed.

Autosave recovery

When tracks exist and the app is not busy, a recovery snapshot is periodically saved (about every two minutes). At startup, the app offers recovery if a snapshot is available.

10 · Mix & export

From arrangement to deliverable

Playback, bounce, and export use the current mix of audible tracks and their arrangement settings.

Mix engine

Combines included tracks at their project offsets, applies gain and pan, honors mute/solo selection, and converts tracks to a common mix format. The final mix is scaled down if its summed peak would clip.

Bounce Mix

Adds a rendered version of the current project mix as a new track, ready for further editing or review.

Export Video

Muxes the current project mix with the source picture from the selected video track. Choose MP4 or Matroska output.

11 · Voice, operations & diagnostics

Helpful controls around the audio

Optional voice access, operation feedback, lightweight diagnostics, and managed cache/temp storage support the creative workflow.

Optional English (UK) voice commands

Enable listening with the Voice button. Supported phrases cover common folders, import, playback, recording, track selection and management, effect actions, undo/redo, FX, mend, bounce, and export.

Requires a microphone and an installed Windows English (UK) speech recognizer. Listening starts only when enabled. Examples: “play”, “open downloads”, “load song [track name]”, “mute track”, “export audio”, “stop listening”.

Status & performance diagnostics

Status messages report current work and errors. The optional Diag display samples process CPU, private memory, and managed memory. It is an informational display, not a full profiler.

Cache controls report storage use and clear downloaded cache files after confirmation. The busy indicator and Cancel button appear during applicable long operations.

Application data & startup audio

Logs, cache, user FX, and temporary files are stored under %LOCALAPPDATA%\BlackStarSwissAudio. Cache pruning and process-specific temporary folders help manage storage.

An optional WAV placed in the project Assets folder can play before the main window appears. Missing or unplayable startup audio does not prevent launch.

12 · Platform & practical requirements

Windows desktop, familiar tools

Use the application on a Windows machine with codecs and resources appropriate to the session’s media.

Platform

  • Windows 10/11, x64 desktop application.
  • Built on .NET 10 for Windows using WPF.
  • Windows Media Foundation is used for supported media decoding and MP3 encoding.
  • FFmpeg is an optional companion dependency for additional format support and video export.

Devices & permissions

Recording requires a working Windows input device and appropriate system permissions. Input device selection and routing are configured in Windows. Voice recognition additionally needs a microphone and installed English (UK) recognizer.

Memory considerations

Audio is held as floating-point PCM in memory. Stereo 44.1 kHz audio uses approximately 21 MB per minute before additional working copies. Effects and mixdowns may need extra memory.

Long tracks and large sessions can require substantial RAM. Leave room for temporary buffers and exported files.

File & codec readiness

Codec support varies by Windows installation and input file. For additional codecs or video export, install FFmpeg as described in the user guide and keep source files available.

For licensed sound assets, verify the specific source’s permissions and terms before redistribution.

13 · Capability summary

A practical studio for the full session

Black Star Swiss Audio brings core multitrack production tasks together in one desktop workspace.

What it enables

  • Import and arrange multiple audio sources and supported video-derived audio.
  • Control track placement, level, pan, mute, and solo.
  • Shape sound with 35 built-in editing, tone, dynamic, modulation, and stereo tools.
  • Audition effects, render edits, and step back through up to eight audio edits per track.
  • Record microphone input and visualize playback or recording through a live-feed spectrogram.
  • Save a project archive, recover from an autosave snapshot, bounce a mix, and export audio/video.
  • Extend the FX library with personal audio or cached HTTPS downloads.

Important current boundaries

  • Processing is rendered into audio; there is no editable non-destructive effect chain.
  • Audio processing and mixdowns use in-memory buffers; no chunked/off-disk editing pipeline is available.
  • Speed edits change pitch as well as duration; pitch-preserving time stretch is not available.
  • Track placement uses numeric offsets; no clip dragging or dedicated reorder gesture.
  • Track meters are estimates, not a master loudness meter or inter-sample peak guarantee.
  • Video source media is referenced, not embedded in the project archive.
  • Codec availability depends on Windows Media Foundation and/or FFmpeg.
Recommended workflow: save a named project regularly, preview unfamiliar processing, monitor levels after layering, keep video sources available until export completes, and leave adequate memory for long sessions.
