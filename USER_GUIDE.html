A practical guide

Black Star Swiss Audio

Import, arrange, edit, mix, save, and export audio with confidence. This guide explains the interface, workflow, built-in tools, project recovery, and current limitations.

1. Quick start

  1. Click Import, or drag audio/video files from File Explorer into the window.
  2. Set each track's Start s, Gain, and Pan. Use M to mute and S to solo.
  3. Select a track and a tool. Adjust the tool parameters, then choose Preview or Apply.
  4. Press Play or Space. Seek, zoom, scroll, or set a loop as needed.
  5. Use Save to save a project. Choose Export Audio for a mix file.

2. The workspace

Top bar

Status bar

Shows status and errors, a busy indicator during long operations, and optional memory/track diagnostics.

Drag the vertical splitters to resize the side panels. Use the Tools and FX toggles above the timeline to collapse or restore them. The interface also includes dark/light palettes and four accent colors.

3. Importing and organizing tracks

Import media

Click Import, choose audio/video files with Open, or drag files into the application. Files are loaded one at a time. The status area identifies the current file and its position in the batch; failed files are summarized at the end while other files continue. The Open dialog also accepts saved .bssa projects (one project at a time).

Cancel cancels the import batch as a whole; you cannot cancel only one file. Each imported file becomes a track. For a video file, the app extracts its audio and remembers the source video path for video export.

Track position and order

Tracks are added in import/add order. Use the Start s field to set a clip's start time from the beginning of the project. A value of 0 starts immediately; a later value inserts silence before the clip. Project duration ends at the end of the latest track.

Tip: There is no clip-drag repositioning or dedicated track-reordering gesture. Use the offset field to place a clip in time.

4. Timeline, selection, and transport

Zoom

The timeline zoom slider ranges from 1× to 16×. Fit returns to a full-project view.

Scroll

The horizontal scroll slider pans across the project when zoomed in.

Ruler and playhead

Ruler tick spacing adapts to the view. A bright line marks playback position; a translucent overlay shows progress.

The spectrogram stays blank until playback or recording begins. It is built column by column from samples sent to the audio output during audio or video-track playback, or from the microphone input while recording; it does not display a precomputed image of the selected clip. Stereo channels are analyzed independently so opposite-phase audio remains visible.

Time selection and trim

Enter Selection s start/end times in seconds in the right panel. Snap 0.1s rounds values to tenths of a second. Click Trim to keep only that range from the selected track. Trimming changes the track audio, but does not automatically change its project offset.

Playback and looping

Use Play, Pause, Stop, or Space. The transport seek slider moves the playhead. For a loop, enter start/end times in Loop s and check Loop; the end must be later than the start and the interval must overlap audio. Uncheck Loop to stop repeating.

Speed

Select a track, choose a speed preset (0.5× to 4×), and click Set speed. This renders an edit: speed changes duration and pitch. It is not a real-time or pitch-preserving playback speed control.

Multiple tracks can sum together. The final mixer scales a mix down if its summed peak would clip. Track meters are estimates for the current playback window—not a master-bus loudness meter or a guarantee against inter-sample peaks.

6. Effects, editing, and undo

  1. Select a track, then select a tool in the left panel (or drag the tool onto a track).
  2. Adjust parameters in the right panel.
  3. Click Preview to audition a temporary rendered result without replacing the track, or Apply to commit it.
  4. Use Undo and Redo to move through recent audio edits.
Effects are destructive renders. There is no editable effect-chain list. To change an applied effect, undo it (if it remains in history) and apply again. Preview is temporary and is not stored as an effect state.

7. Recording and sound effects

Record audio

  1. Connect and select the Windows recording device in system audio settings.
  2. Press the red Record button to start; the level and recording status update.
  3. Press Record again to finish. The recording is added as a new track.

Recording requires a working Windows input device and appropriate permissions. Device selection and routing are configured outside the application.

FX library

  • Double-click one of the 19 built-in procedural sounds to add it as a new track. Categories include noise, atmosphere, synth, cinematic, metal, and foley.
  • Enter an HTTPS audio-file URL and choose Get to download and import it. Downloads are limited to 200 MB and cached locally.
  • Archive links open in your browser. Review each asset's licence before sharing or redistributing it; links do not grant rights.

8. Saving, opening, and recovery

  • Save creates a .bssa archive. It embeds each track's current audio and saves track name/order, offset, gain, pan, mute/solo state, and source references.
  • Open replaces the tracks currently in the workspace. Save the current project first if you need to keep it.
  • Autosave runs about every two minutes when tracks exist and the app is not busy. At startup, the app offers recovery if an autosave is available. You can also choose Recover.
  • Autosave is a recovery snapshot, not a named project backup. Save named project files regularly.
  • The video file itself is not embedded in a project. Keep the referenced source video available if you plan to export video later; the project's audio remains embedded.

9. Mixing and exporting

  • Bounce Mix adds the current mixed result as a new track, reflecting track offsets and mixer settings.
  • Export Audio renders the current project mix. A preflight dialog shows duration, sample rate, channel count, and approximate PCM WAV size.
  • For MP3, select 128, 192, or 256 kbps in the right panel. The bitrate setting does not affect WAV or other formats.
  • Export Video muxes the current project mix with the source video associated with the selected video track. Choose MP4 or Matroska output.
  • FFmpeg is required for video export, video formats not supported by Windows Media Foundation, and FLAC, OGG, Opus, and AAC/M4A export. MP3 encoding uses Windows Media Foundation.

Long operations show a busy indicator and a Cancel control when cancellation is supported. Progress is not reported as a precise percentage for every operation.

10. Themes, accessibility, cache, and diagnostics

Appearance

Check Light to switch palettes. Select Gold, Teal, Violet, or Blue for the accent. Timeline zoom changes horizontal time scale, not text size.

Keyboard and focus

Standard Tab navigation, visible keyboard focus on key controls, accessible names for icon-only controls, and the shortcuts below are available. There is no separate font scaling option.

Diagnostics

Enable Diag to display process working-set memory, managed memory, and track count. This is informational, not a profiler.

Cache and temporary files

Cache reports cache/temp usage. Clear asks before removing downloaded cache files; loaded tracks and partial active downloads are unaffected.

Logs, cache, and temporary files are under %LOCALAPPDATA%\BlackStarSwissAudio. The file cache is pruned by age/size. Temporary working files are cleaned during application startup and shutdown.

13. Limitations and safe-working tips

Memory use: Audio is held as floating-point PCM in memory. Stereo 44.1 kHz audio uses roughly 21 MB per minute before extra working copies. Very long tracks or large numbers of tracks can require substantial RAM.
  • No chunked/off-disk editing yet: effects, mixdowns, project loading, and exports use in-memory buffers.
  • No editable non-destructive effect chain: applied effects render into track audio. Undo is limited to eight audio edits per track.
  • Speed changes pitch: pitch-preserving time stretching is not available.
  • Basic selection: trim uses numeric seconds; Cut uses clip percentages. There are no draggable trim handles or beat/tempo snapping.
  • Basic track layout: tracks are added in order and positioned with Start s. There is no dedicated track reorder or clip-drag positioning tool.
  • Batch import cancellation: a batch can be cancelled, but a single file cannot be cancelled independently. The busy indicator is not an exact progress percentage.
  • Meters are estimates: they are not master loudness meters and do not guarantee against inter-sample peaks.
  • Autosave is periodic: recent work since the last snapshot can be lost after a crash. Save named projects frequently.
  • Video is referenced, not embedded: keep the source video available until video export is complete.
  • External codec/licence requirements: FFmpeg and Windows codecs affect format support. Third-party FX licences remain your responsibility.

Good habits

  1. Save a named .bssa project before applying a series of effects.
  2. Preview unfamiliar effects and check levels after adjusting gain or layering tracks.
  3. Save a copy before major edits; leave adequate memory and disk space for long audio.
  4. Keep source video files in place until video export is finished.
  5. Use the status message and logs under %LOCALAPPDATA%\BlackStarSwissAudio\logs to help diagnose errors.
